# API Surface Index

## Authority And Projection Boundary

本文件是人类可读索引，不是业务语义 Owner，也不得独立批准或改变业务语义。

- 长期业务语义唯一 Owner：[`MAIN_CONTRACT_MATRIX.md`](./MAIN_CONTRACT_MATRIX.md)。
- 实际传输合同：`backend/app/**/router.py` 中的 FastAPI route 与 `backend/app/**/schemas.py`、`backend/app/errors/schemas.py` 中的 Pydantic schema。
- 机器可读投影：运行时 `app.openapi()`；approved API-v1 snapshot 为 `backend/tests/contract/snapshots/api-v1.openapi.json`。
- Frontend transport projection：由上述 snapshot 机械生成的 `frontend/src/api/generated.ts`；不得手工修改。
- 本索引中的 error code、status 和 schema name 均是 route/OpenAPI 的摘录；发生冲突时，以 route + Pydantic 和当前 OpenAPI 为准，本文件只能跟随更新。

当前正式 surface 共 22 个 operations，base prefix 为 `/api/v1`，OpenAPI info version 为 `0.1.0`。

## Compatibility And Breaking-Change Rule

全部 operations 共享 `API-v1 gate`：

- reader-compatible additive optional field 或 enum 扩展可以进入同一 major，但必须更新并审核 snapshot、generated TypeScript 和本索引；
- method/path/operation 删除或重命名、property 删除或重命名、type 变化、required set 变化、enum 收缩、既有 success/error status 删除或变化均为 breaking；
- breaking change 必须走显式 major-version migration；不得通过直接重写 approved baseline 绕过 gate；
- `API_CONTRACT_BASE_REF=<prior-approved-revision> make check-api-contracts` 从当前变更不可覆盖的 Git revision 读取 baseline，同时验证 exact snapshot、严格 breaking diff、统一 error envelope 和 frontend generated-type drift；不接受当前 worktree snapshot 作为 breaking comparison baseline。

下表每行的 Compatibility 值 `API-v1 gate` 指向本节，不在 endpoint 行内重新定义规则。

## Consumer And Schema Notes

- `frontend/src/api/generated.ts` 是唯一 generated transport types 文件；`frontend/src/api/types.ts` 只为 UI-local view refinements 和 transport aliases 提供稳定 import surface，不复制 Pydantic field lists。
- `frontend/src/api/client.ts` 只拥有 fetch/error transport；各 feature API wrapper 不拥有业务语义。
- E2E 中的 direct `fetch` 仍是 consumer，不是 schema Owner。
- 两个 binary operations 显式使用 `response_model=None` 并声明准确 MIME；一个 delete operation 使用 empty `204`；其余 19 个 JSON operations 必须声明明确 `response_model`。全部 operations 使用统一 error responses。
